# AI-Powered Tools Collection

A collection of web-based productivity tools designed to enhance your workflow and daily tasks.

## 🛠️ Tools Included

1. **[Advanced PDF Editor](./Local HTML PDF Editor - Upload multiple PDFs, select page ranges, reorder, merge, preview, and download v2.html)**  
   Complete PDF suite: upload, reorder pages, merge multiple files, and preview before downloading.

2. **[HEIC Converter](./HEIC to JPGPNG Converter.html)**  
   Instantly convert Apple's HEIC image format to widely compatible JPG and PNG formats.

3. **[Smart Expense Splitter v4](./Expense Splitter v4.html)**  
   Fairly divide group expenses with intelligent calculation and detailed cost breakdowns.

4. **[Time Zone Converter](./Time Zone Converter v2.html)**  
   Convert time across different global zones with real-time updates and world clock display.

5. **[Color Palette Generator](./Advanced Color Palette Generator v2.html)**  
   Generate beautiful color schemes with harmony rules and export options for designers.

6. **[Weather Dashboard](./Weather Dashboard with OpenMeteo API v2.html)**  
   Real-time weather information with detailed forecasts using OpenMeteo API integration.

7. **[Currency Converter](./Currency Converter.html)**  
   Convert currencies with real-time exchange rates and support for multiple countries.

8. **[JSON Tree Viewer](./JSON Tree Viewer.html)**  
   Visualize JSON data with an interactive tree structure, syntax highlighting, and collapsible nodes.

9. **[Whitespace Remover](./Multiple Whitespace Remover Editor.html)**  
   Clean up text by removing excessive whitespace, line breaks, and formatting inconsistencies.

10. **[Word Transform](./Word Transform.html)**  
    Transform text with various formatting options including case conversion and styling tools.

11. **[Column Data Formatter](./Column Data Formatter.html)**  
    Format and organize column-based data with alignment options and sorting capabilities.

12. **[Date Calculator](./Date Calculator.html)**  
    Calculate the exact number of days between today and any future or past date.

13. **[Productivity Timer](./Timer.html)**  
    Manage your time effectively with a customizable timer interface and Pomodoro logic.

## 🚀 Features

- **No installation required**: Works directly in your browser.
- **Mobile-friendly**: Responsive design for all devices.
- **Privacy-focused**: All processing happens locally.
- **Fast and lightweight**: Optimized for performance.

## 💻 Usage

1. Click on any tool to launch it.
2. Each tool works independently with its own interface.

## 🛠️ Technical Details

- Built with HTML5, CSS3, and vanilla JavaScript.
- Uses Font Awesome for icons.
- OpenMeteo API for weather data.
- No external frameworks required.
